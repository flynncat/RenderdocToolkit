# 用户使用指南

本文面向第一次接触本项目的用户，介绍如何使用桌面工具中的三个主要功能页。

## 1. 界面概览

应用启动后，顶部会显示三个主要 Tab：

- `性能`
- `性能 Diff`
- `资产批量导出`

右上角提供两个全局入口：

- `环境设置`
- `刷新环境状态`

建议首次启动时先打开 `环境设置`，确认 RenderDoc 与模型服务相关配置可用。

![应用首页总览](images/overview-home.png)

## 2. 环境设置

`环境设置` 弹窗主要用于确认以下项目：

- `RenderDoc Python Path`
- `LLM Provider`
- `OpenAI-compatible Base URL`
- `OpenAI-compatible API Key`
- `OpenAI-compatible Model`
- `renderdoc_cmp 根目录`

建议检查流程：

1. 确认 RenderDoc 已安装
2. 填写或校正 RenderDoc Python 路径
3. 如果要启用在线模型，填写 OpenAI-compatible 配置
4. 确认 `renderdoc_cmp` 路径正确
5. 点击 `保存并应用`
6. 观察下方检测结果，确认工具链已准备完成

## 3. 性能

适用于分析单个 `.rdc` 的 Pass 级性能热点。

### 输入项

- `RenderDoc .rdc 路径`
- 可选：`RenderDoc 目录` — 指定本次分析使用的 RenderDoc 安装目录。不填时走全局 `环境设置` 中的默认配置。当你用魔改版或其他版本 RenderDoc 抓帧时，可在此指定对应版本的目录。

### 使用步骤

1. 选择单个抓帧
2. 如果该 `.rdc` 由非默认版本 RenderDoc 生成，填写对应的 RenderDoc 目录
3. 点击 `执行性能分析`
4. 使用排序维度和排序方向调整结果顺序
5. 查看性能表中的热点项
6. 结合右侧图表和提示信息理解开销分布

### 可关注信息

- 排序后的热点 Pass
- 图表中的阶段开销分布
- 线框预览
- 运行日志中的附加提示

## 4. 性能 Diff

适用于对比两份 `.rdc` 的性能表现差异。

### 输入项

- `Base .rdc 路径`
- `New .rdc 路径`
- 可选：`RenderDoc 目录`
- 可选：`Malioc 路径`
- 可选：`Strict Mode`
- 可选：`Verbose`

### 使用步骤

1. 选择两份待比较的抓帧
2. 如果该 `.rdc` 由非默认版本 RenderDoc 生成，填写对应的 RenderDoc 目录
3. 如有需要，补充 Malioc 路径
4. 点击 `执行性能 Diff`
5. 查看中间区域生成的报告
6. 结合右侧历史与日志定位异常变化

### 输出区域

- `cmp 结果`
- HTML 报告内嵌窗口
- `cmp 历史`
- `运行日志`

![性能 Diff 页面](images/cmp-report.png)

## 5. 资产批量导出

适用于从抓帧中批量导出资产，并对 CSV 做模型格式转换。

### 主要流程

1. 读取 Pass 列表
2. 选择导出范围
3. 设定输出格式
4. 在导出前确认批量映射
5. 查看导出结果与日志

### Pass 选择

支持以下方式：

- 单个 Pass
- Pass 区间
- 手动输入单个 EID
- 手动输入起始 / 结束 EID

### 导出格式

- `FBX`
- `OBJ`
- 贴图格式：`PNG`、`TGA`、`HDR`、`EXR`

### 批量映射确认窗口说明

- 只要本次导出启用了 `FBX` 或 `OBJ`，正式导出前都会先弹出一次批量映射确认窗口。
- 如果当前选择的是 `Pass` 区间或手动 `EID` 范围，窗口也只会弹出一次，不会要求你对范围内的每个 Pass 逐个确认。
- 这个窗口会从当前导出范围里挑一个样本 draw / `EID`，展示自动识别出来的顶点列映射，方便你快速确认这一批数据的大致结构。
- 你在窗口里确认的映射，会作为这一次批量导出的统一优先覆盖。
- 真正执行导出时，工具仍会对每个 draw 的 CSV 单独做自动识别；如果某个 draw 不存在你手动指定的列，会自动回退到该 draw 的自动识别结果，不会再次弹窗。
- 如果本次不导出 `FBX` / `OBJ`，则不会出现这个批量映射确认步骤。

## 6. CSV 列映射预览

该区域既可作为资产导出的辅助，也可以独立使用。

### 支持的输入方式

- 单个 CSV 文件
- 多个散点 CSV 文件路径
- 单个目录

如果输入多个文件路径，建议每行一个路径。

### 推荐步骤

1. 通过 `浏览` 选择一个或多个 CSV 文件
2. 或通过 `目录` 选择一个包含 CSV 的目录
3. 点击 `识别列映射`
4. 检查 `Position`、`Normal`、`UV`、`Tangent` 等列是否合理
5. 如有需要手动调整映射
6. 点击 `按当前映射开始批量转换`

### 当前行为

- 如果当前已经选中某个资产导出任务，则转换结果会挂到该任务下
- 如果当前没有选中任务，工具会自动创建一个“手工 CSV 转换任务”
- 批量选择多个 CSV 或目录时，预览面板只展示一个样本 CSV 的自动识别结果
- 真正执行批量转换时，工具会对每个 CSV 单独自动识别；你手动指定的列会作为统一优先覆盖
- 如果某个 CSV 不存在你手动指定的列，工具会自动回退到该文件自己的自动识别结果，并在任务结果中记录回退说明
- 手工 CSV 转换完成后，界面不再自动打开输出目录，避免额外弹出系统窗口

## 7. 常见问题

### Q1：为什么界面提示某些环境未就绪？

通常是以下路径未配置正确：

- RenderDoc Python Path
- `renderdoc_cmp` 根目录
- 在线模型配置

建议优先到 `环境设置` 中核对。

### Q2：CSV 转换必须先做资产批量导出吗？

不必须。当前 CSV 转换支持独立使用；如果没有选中导出任务，工具会自动创建一个手工转换任务。

### Q3：批量导出一个 Pass 范围时，是否需要每个 Pass 都确认一次映射？

不需要。当前批量映射确认窗口只会在导出开始前弹出一次。确认后，工具仍会对范围内每个 draw 的 CSV 单独做自动识别；如果某个 draw 不存在你手动指定的列，会自动回退到该 draw 的自动识别结果，不会再次弹窗。

### Q4：如何用不同版本的 RenderDoc 分析不同的 `.rdc` 文件？

`性能` 和 `性能 Diff` 两个 Tab 都支持在每次提交任务时指定 `RenderDoc 目录`。如果你同时有公版和魔改版 RenderDoc 生成的 `.rdc`，只需在提交时分别填写对应版本的安装目录即可。不填时仍然使用 `环境设置` 中的全局默认路径。

分析完成后，任务摘要中会显示本次实际使用的 RenderDoc 路径和来源（任务覆盖 / 全局设置 / 内置 / PATH），方便事后排查。

### Q5：为什么不同抓帧来源下信息显示不完全一致？

不同 API、不同平台和不同抓帧方式下，RenderDoc 可提供的数据粒度不同，移动端或真机抓帧尤其需要结合原始 RenderDoc 视图一起判断。
